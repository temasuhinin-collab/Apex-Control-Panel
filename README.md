# Apex Control Panel

Локальная панель игровых настроек для Apex Legends. Автор: **Artem Sukhinin**.

## Возможности
- Тёмный интерфейс с навигацией и адаптивной компоновкой.
- Настройки DPI, игровой чувствительности, ADS, FOV и Raw Input.
- Пользовательские профили: создать, переименовать, применить и удалить.
- Чек-лист подготовки ПК к игре и локальные заметки.
- Сохранение данных локально в хранилище приложения.
- Сборка portable `.exe` через GitHub Actions.

## Важно
Приложение **не управляет мышью**, не автоматизирует компенсацию отдачи и не изменяет файлы Apex Legends. Значения профилей нужно переносить в настройки игры вручную. Это снижает риск конфликтов с античитом и правилами игры.

## Сборка EXE на GitHub
1. Создай новый репозиторий на GitHub, например `Apex-Control-Panel`.
2. Загрузи в корень репозитория файлы `package.json`, `main.js`, `index.html`, `styles.css`, `renderer.js`, `README.md` и папку `.github/workflows/build.yml`.
3. Открой вкладку **Actions**. Если GitHub попросит включить Actions — включи.
4. Запусти workflow **Build Windows EXE** через **Run workflow**, либо внеси commit в `main`.
5. Дождись зелёной отметки выполнения, открой завершённый запуск workflow и найди **Artifacts**.
6. Скачай `Apex-Control-Panel-Windows.zip`, распакуй его и запусти `.exe`.

## Запуск локально (необязательно)
Требуется Node.js 20+:
```bash
npm install
npm start
```

## Данные и приватность
Профили и заметки хранятся локально в хранилище приложения на компьютере. Приложение не отправляет их на сервер.
